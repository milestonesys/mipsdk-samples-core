# Milestone VideoOS SDK Core samples

This repository is intended to host samples for the
[Milestone VideoOS SDK Core](https://www.nuget.org/packages/MilestoneSystems.VideoOS.Platform.SDK.Core)
NuGet package.

Sample code will be added to this repository over time. When samples become
available, each sample will include its own directory and any sample-specific
instructions.

## Prerequisites

Before running the samples, make sure you have:

- A supported .NET development environment
- Access to an XProtect environment relevant to the scenario being demonstrated
- The prerequisites described in the Milestone developer documentation

## Documentation and support

Relevant documentation for the SDK and related developer resources is available
at the [Milestone Developer Portal](https://portal.developer.milestonesys.com).

The SDK package used by the samples is published on NuGet:

- [MilestoneSystems.VideoOS.Platform.SDK.Core](https://www.nuget.org/packages/MilestoneSystems.VideoOS.Platform.SDK.Core)

## Repository structure

This respository is structured in one main directory as follows:
```bash
mipsdk-samples-core
├── README.md
├── LICENSE
└── src
    └── sdk-core-crud
    └── StableFpsRecorder
```
